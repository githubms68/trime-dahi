## 1. 安装

1. 下载 release 里的 **arm64-v8a** APK（多数手机；不确定就用这个）。
2. 安装后打开「同文输入法大海版」，按引导选择 Rime 用户数据目录（用默认的应用私有目录最省事）。
3. 系统设置 → 语言与输入法 → 启用「同文输入法大海版」→ 设为默认。

> 包名 `com.osfans.trime.dahi`，**可以和原版同文、CatTrime、BiBi 版共存**，互不覆盖。
> 覆盖升级只要求两次构建用**同一个签名密钥**，与密码 / 别名无关。

## 2. 第一次打开设置

主界面右上角齿轮 → 大海版专有入口：

| 入口 | 干什么 |
|---|---|
| **样式编辑** | 18 组颜色 + 30 项尺寸的可视化调整，实时预览、模板、**导入导出皮肤** |
| **键盘背景** | 相册图 / GIF / 视频做键盘底板，支持裁剪、模糊、透明度、4 种填充 |
| **声情意象** | 说话时的键盘动效（11 种），可排序、可调振幅与灵敏度 |
| **剪贴板分类** | 分类新建 / 改名 / 删除 / 排序（剪贴板与收藏夹共用） |
| **排序与短语** | 查看并清理候选词自定义顺序、自定义短语 |
| **首页标语** | 自定义首页标题下那句小字（4 条预设 / 自定义 / 不显示） |
| **诊断信息** | 一键导出「版本 + 机型 + 关键设置」，方便反馈问题 |

## 3. 三分钟做一套自己的皮肤

**① 先定底色**

设置 → 键盘背景 → 打开「启用自定义键盘背景」→ 从相册选图（可裁剪、可模糊）。
竖屏、横屏、候选栏可以各放一张；GIF 和视频也认。

**② 再调按键，让它让出背景**

样式编辑 → 按键与键盘 →「按键底色」把不透明度拉低（或用「透明按键」模板）→ 背景就透出来了。

**③ 调完导出，发给任何人**

样式编辑 → 模板 → 导出 JSON。对方在同一个位置导入即可，**不需要他懂任何配置**。
你的配色、尺寸、圆角、间距、工具栏图标颜色，全都在这个文件里。

> 这就是这套设计最想打通的一公里：**皮肤作者和用户之间，不再隔着"部署"这一步。**

## 4. 长按，是最重要的手势

- **长按候选词**：前移 / 置顶 / 移到上页 / 移到页首……数字键会跟着新顺序选字。
  调乱了：设置 → 排序与短语 → 候选词自定义顺序 → 清空。
- **长按剪贴板条目**：编辑 / 分享 / 分词 / 收藏 / 置顶 / 设置分类 / 删除 / 设为自定义短语 / 批量。
  搜索浮层里长按，是同一套菜单。

## 5. 备份（换机必看）

设置 → 配置 → 备份与还原：**全程加密**（AES-256-GCM + PBKDF2 20 万次迭代），可分别勾选
首选项 / 剪贴板 / 收藏夹 / 声情意象 / 候选排序 / 自定义短语 / 键盘背景。

还原前会显示「备份时间 / 来源版本 / 文件大小」；若备份来自更新版本，会明确提示——**那不是密码错误**。

## 6. 出问题怎么办

设置 → **诊断信息** → 导出，把生成的 txt 发出来即可（不含剪贴板内容、不含备份密码）。

## 二、备份与还原（加密）

- 文件格式：`magic(8B) | version(1B) | salt(16B) | iv(12B) | AES-256-GCM(密文+tag)`，**绝不明文落盘**。
- KDF：PBKDF2-HMAC-SHA256，20 万次迭代，256 bit。
- **7 个可独立勾选项**：首选项 / 剪贴板 / 收藏夹 / 声情意象 / 候选排序 / 自定义短语 / 键盘背景（图片、GIF、视频 ≤4MB）。
- 短语还原支持 **覆盖 / 合并**。
- 还原前显示「备份时间 / 来源版本 / 文件大小」；备份来自更新版本时明确提示（不是密码错）。
- 密码错与文件损坏分别提示，不再一律说“密码错误”。

## 三、语音

- **说点啥 AIDL 联动**：三个开关（AIDL 语音 / 录音时暂停其他媒体 / 工具栏麦克风）；主题里绑 `command: voice_toggle` 可做点按开关。
- **声情意象 11 种动效**：清纹徐流、静息沉光、星星点点、环漪悠漾、碧浪腾舒、明律铿锵、迷雾萦回、海浪怒吼、一片空白、随遇随机、声随情迁。
  可拖动排序、可独立取色、有最大振幅上限与自适应灵敏度；两个快捷入口（工具栏 ♬ / 键盘左上角三点菜单）。

## 四、悬浮键盘

两个入口（工具栏按钮 / 三点菜单）；`－ / 停靠 / ＋` + 两个空档拖动；
**横竖屏各自独立的横向、纵向缩放**（右下角比例把手）；不占用应用内容区，键盘外点击可穿透；位置与比例记忆。

## 五、候选词引擎

- **长按排序**：忘记该词 / 前移 / 后移 / 置顶 / 垫底 / 重置 / 移到上页 / 下页 / 页首 / 页尾。
- 取完整候选表后整体重排再切页 → **跨页真正生效**；重排后按显示位置补序号。
- **数字键按显示位置选字**；上/下页键改为翻应用侧页；组字结束自动复位。
- **自定义短语**：代码 → 正文，任何方案可用；与排序共用同一套顺序体系。
- **排序与短语法管理页**：列出全部记录、单条删除、一键清空。
- 键盘候选栏序号开关；候选窗口翻页箭头点击区 32×32dp、间隔 20dp。

## 六、外观

### 样式编辑（不碰任何主题 yaml）

- **颜色 17 组 / 3 大类**：按键与键盘（含工具栏图标）、候选栏、气泡。
- **尺寸 30 项 / 6 分组**：按键、间距与阴影、候选栏、注释与上标、气泡、高级微调。
- 分组可排序（组内上移/下移/置顶/垫底）、可恢复默认顺序（不动数值）。
- **实时预览**：悬浮固定；候选词按文字宽度流式排布不重叠；**启用自定义背景时直接用真实背景图铺底**（样式与背景的合成效果）。
- 取色器：色相条 + 饱和度/明度面板 + A/R/G/B 滑块 + 十六进制。
- 模板：快速模板（原样/透明按键/深色/浅色）+ 2 个自定义槽 + JSON 导入导出。

三层覆盖保证「任何主题都能改」。

### 键盘背景

- 4 个槽位：竖屏 / 横屏 / 候选栏 / 视频，各自记忆数据源与填充模式。
- 相册选图（支持 GIF 自动识别循环）、视频（静音等比循环）；**裁剪页**（拖动 + 双指缩放）。
- 填充 4 种、高斯模糊 0–40、透明度、实时预览；随加密备份一起走。
- **省电**：GIF 按自身帧率（约 20fps）重绘而不是跟着屏幕刷新率；键盘不可见时暂停视频解码。

## 一、先说全篇最特别的一件事：声情意象

**这是本项目原创、目前没有第二款输入法做过的功能。**

用语音输入时，键盘底部会随着你的声音起伏流动。不是那种机械的"音量条"——是八套**带情绪内核**的动效，每一套对应一种说话状态：

| 动效 | 情绪内核 | 强度 |
|---|---|---|
| 清纹徐流 | 平和舒缓、娓娓道来 | ★★☆☆☆ |
| 静息沉光 | 沉静内敛、若有所思 | ★★☆☆☆ |
| 星星点点 | 轻快跳跃、心情明亮 | ★★★☆☆ |
| 环漪悠漾 | 温润从容、不急不缓 | ★★★☆☆ |
| 碧浪腾舒 | 兴致盎然、灵动外放 | ★★★★☆ |
| 明律铿锵 | 理性清醒、条理清晰 | ★★★★☆ |
| 迷雾萦回 | 思绪纷乱、遐想恍惚 | ★★★★☆ |
| 海浪怒吼 | 澎湃汹涌、大海无量 | ★★★★★ |

还有三种"模式"：

- **一片空白**：关闭动效，只留干净键盘。
- **随遇随机**：每次语音输入随机挑一套，天天不重样。
- **声随情迁**：**根据你声音的活跃度，在八套动效之间自动过渡**——轻声细语时是清纹徐流，越说越激动会自然推到海浪怒吼。灵敏度可调。

能调的细节：动效颜色（跟随键盘配色，或固定一个颜色）、动效透明度（100%–150%，主题偏淡时可以加深）、最大振幅上限（避免盖住候选）、顺序（拖动排序）、工具栏 ♬ 按钮一键切换。

> 为什么值得单独说：键盘是"看不见的器官"，绝大多数输入法只在**结果**（打出什么字）上优化，没有人在**过程**（说话/打字时的身体感）上做过设计。声情意象是把"说话的情绪"变成可见的形状——这也是这个版本最想让你先看到的东西。

## 二、第二件：键盘的每一条参数，现在都在你手里

同文最迷人的地方是「什么都能改」；最折磨人的地方是「只能用 YAML 改」。

想要按键圆角大一点、候选栏矮一点、气泡阴影淡一点、工具栏图标换个颜色——
都得打开主题目录里那份几百行的 yaml，在一堆 `key_back_color` / `keyboard_padding` 里
凭经验填数字，然后「部署」、回键盘看、不对再改。想装别人做的皮肤更麻烦：先学会把文件放对地方、改对 `style`。

**大海版把这一整条链路删掉了。**

| 以前 | 现在 |
|---|---|
| 打开编辑器找键名 | 点开「样式编辑」：18 组颜色 / 30 项尺寸，按分组排好 |
| 手填 `#RRGGBB` | 取色盘：色相条 + 饱和度&明度面板 + A/R/G/B + 十六进制 + 透明度 |
| 凭经验猜 dp 数值 | 拖滑杆，预览立刻变——用的是**你真实的键盘背景图**，不是示意色块 |
| 改完部署、重启、回键盘看 | 改完即时生效，键盘视图当场重建 |
| 皮肤只是"一个包"，别人装了还怕撞主题 | **一键导出皮肤 JSON，别人一键导入**，配色尺寸圆角间距原样带走 |
| 想反悔 | 「恢复默认」，或换回上一个模板槽 |

细节不省：三层覆盖（颜色 fallback 链 → 30+ 中文别名键 → 按键层 `GradientDrawable`）
保证**任何第三方主题都能改**——包括那些拿图片当按键底色的主题（这类主题以前怎么改颜色都没反应，
因为它的底色根本不是"颜色"）。

**怎么把皮肤给别人：**

1. 调好 → 样式编辑 → 模板 → 保存到自定义槽 → 导出 JSON
2. 把 JSON 发出去
3. 对方：样式编辑 → 模板 → 导入 → 选中 → 应用

不需要他懂任何配置，也不需要他重启。

> **这才是同文「自由」该有的样子**：自由不该以"必须会写配置"为门槛。
> 你做一套，朋友导入就能用；他在你的基础上改两笔，再导出给下一个人。
> 同文生态里目前没有第二款做到这一点——这不是"又多了一个主题可选"，
> 而是**皮肤第一次变成了可以互相传递的东西**。

```
文件格式：magic(8B "DAHIBAK1") | version(1B) | salt(16B) | iv(12B) | AES-256-GCM(ciphertext + 16B tag)
密钥派生：PBKDF2-HMAC-SHA256 (200,000 次迭代) → 256-bit Key
```

- 可选备份：**首选项 / 剪切板 / 收藏夹 / 声情意象参数**
- 还原时同样可单项勾选，**整体覆盖**所选数据，有确认提示
- 文件被其他任何应用、任何人读取也只能得到一堆乱码

### 🎤 「说点啥」语音输入联动（AIDL）

- 三开关：**说点啥 AIDL 语音输入 / 录音时暂停其他媒体 / 工具栏麦克风按钮**
- 触发方式：**长按空格键**（主题映射 `VOICE_ASSIST`）或 **工具栏麦克风**
- 识别结果经 `onPartial/onFinal` 回填/上屏，含纠错上屏观测
- 需自行安装「说点啥」并开启「允许外部输入法联动 (AIDL)」

## 📥 下载与安装

1. 进入 **[Releases](https://github.com/githubms68/trime-dahi/releases/latest)**
2. 下载最新 **`...-arm64-v8a-release.apk`**（现代手机首选，旧机型选 `armeabi-v7a`）
3. 传手机安装（首次需允许「安装未知来源应用」）
4. 系统「语言和输入法」中启用 **「同文输入法大海版」** 并切换
5. 首次自动部署 Rime 方案，稍等即可使用

支持 ABI：`arm64-v8a`（推荐） / `armeabi-v7a` / `x86` / `x86_64`

## ❓ 常见问题

| 问题 | 答案 |
|------|------|
| **能和官方同文一起装吗？** | 能，包名不同，互不影响 |
| **语音没反应/提示未找到服务？** | 1) 安装「说点啥」 2) 开启「允许外部输入法联动 (AIDL)」 3) 后台锁定「说点啥」常驻 |
| **声情意象动效不显示/卡顿？** | 降低「最大振幅上限」、关闭「工具栏按钮」省资源；动效为纯自绘，无 GPU 依赖 |
| **提示签名异常/来源未知？** | 个人自签名、非应用商店分发，属正常现象 |
| **怎么更新？** |  大海版老用户Releases下载新版直接覆盖安装更新，重新覆盖安装不会清除旧版数据。**但仍然建议更新前，用大海版自带加密备份进行备份** |
