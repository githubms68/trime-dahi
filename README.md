## 一、先说全篇最特别的一件事：声情意象

**这是本项目原创、目前没有第二款输入法做过的功能。**

用语音输入时，键盘底部会随着你的声音起伏流动。不是那种机械的"音量条"——是八套**带情绪内核**的动效，每一套对应一种说话状态：

| 动效 | 情绪内核 | 强度 |
|---|---|---|
| 清纹徐流 | 平和舒缓、娓娓道来 | ★★☆☆☆ |
| 静息沉光 | 沉静内敛、若有所思 | ★★☆☆☆ |
| 星星点点 | 轻快跳跃、心情明亮 | ★★★☆☆ |
| 环漪悠漾 | 温润从容、不急不缓 | ★★★☆☆ |
| 碧浪腾舒 | 兴致盎然、灵动外放 | ★★★★☆ |
| 明律铿锵 | 理性清醒、条理清晰 | ★★★★☆ |
| 迷雾萦回 | 思绪纷乱、遐想恍惚 | ★★★★☆ |
| 海浪怒吼 | 澎湃汹涌、大海无量 | ★★★★★ |

还有三种"模式"：

- **一片空白**：关闭动效，只留干净键盘。
- **随遇随机**：每次语音输入随机挑一套，天天不重样。
- **声随情迁**：**根据你声音的活跃度，在八套动效之间自动过渡**——轻声细语时是清纹徐流，越说越激动会自然推到海浪怒吼。灵敏度可调。

能调的细节：动效颜色（跟随键盘配色，或固定一个颜色）、动效透明度（100%–150%，主题偏淡时可以加深）、最大振幅上限（避免盖住候选）、顺序（拖动排序）、工具栏 ♬ 按钮一键切换。

> 为什么值得单独说：键盘是"看不见的器官"，绝大多数输入法只在**结果**（打出什么字）上优化，没有人在**过程**（说话/打字时的身体感）上做过设计。声情意象是把"说话的情绪"变成可见的形状——这也是这个版本最想让你先看到的东西。

- 📌 **收藏夹置顶**：与剪切板行为完全一致，含图钉指示
- 🌉 **搜索框桥接**：`ClipboardSearchBridge` 将 Rime 提交文本重定向到搜索框，非激活态零拦截

### 🔐 备份与还原 —— **军工级加密，绝不明文落盘：你的数据只有你能读取、你做主；别人拿去只能是一堆乱码废物**

```
文件格式：magic(8B "DAHIBAK1") | version(1B) | salt(16B) | iv(12B) | AES-256-GCM(ciphertext + 16B tag)
密钥派生：PBKDF2-HMAC-SHA256 (200,000 次迭代) → 256-bit Key
```

- 可选备份：**首选项 / 剪切板 / 收藏夹 / 声情意象参数**

- 文件被其他任何应用、任何人读取也只能得到一堆乱码

## 📥 下载与安装

1. 进入 **[Releases](https://github.com/githubms68/trime-dahi/releases/latest)**
2. 下载最新 **`...-arm64-v8a-release.apk`**（现代手机首选，旧机型选 `armeabi-v7a`）
3. 传手机安装（首次需允许「安装未知来源应用」）
4. 系统「语言和输入法」中启用 **「同文输入法大海版」** 并切换
5. 首次自动部署 Rime 方案，稍等即可使用

支持 ABI：`arm64-v8a`（推荐） / `armeabi-v7a` / `x86` / `x86_64`

## ❓ 常见问题

| 问题 | 答案 |
|------|------|
| **能和官方同文一起装吗？** | 能，包名不同，互不影响 |
| **语音没反应/提示未找到服务？** | 1) 安装「说点啥」 2) 开启「允许外部输入法联动 (AIDL)」 3) 后台锁定「说点啥」常驻 |
| **声情意象动效不显示/卡顿？** | 降低「最大振幅上限」、关闭「工具栏按钮」省资源；动效为纯自绘，无 GPU 依赖 |
| **提示签名异常/来源未知？** | 个人自签名、非应用商店分发，属正常现象 |
| **怎么更新？** |  大海版老用户Releases下载新版直接覆盖安装更新，重新覆盖安装不会清除旧版数据。**但仍然建议更新前，用大海版自带加密备份进行备份** |
