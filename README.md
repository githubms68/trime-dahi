# 一、V2 全新增加：输入统计（V1 完全没有）

V1 的 README 里，「统计」「词云」「热力图」这些词**一次都没出现过**。V2 从零建了一套完整的输入统计。

## 1.1 数据层

- **每个方案独立的「生涯桶」**：永不重置，与「今日 / 本周 / 本月 / 今年」四个周期桶**并行累加**。
  （V1 之后刚做时只有两个标量，导致生涯页一半指标是空的——V2 修好了。）
- **升级不丢历史**：加生涯桶时用「今年」桶的数据回补历史指标。
- **切换方案不串数据**：由方案切换事件直接归位，不再出现「切完方案第一键记到上一个方案」。

## 1.2 指标

| 指标 | 说明 |
|---|---|
| 汉字数 / 上屏次数 | 只算真正上屏的汉字，粘贴、整段上屏不计速度 |
| 击键数 | 每次按键都算 |
| **击键速度（键/秒）** | 看手速 |
| **每键产出（字/键）** | 看方案 + 词库省不省力 |
| **平均码长** | 点候选上屏也补记编码（此前永远是 0） |
| **首选率 / 翻页率** | 候选质量 |
| **修正率** | 退格占比 |
| **极速 / 均速** | 极速滑窗下限 5 秒、样本不足 5 字不算、单次 >20 字不计（不再是「极速 186 vs 均速 23」这种荒谬值） |
| **段位 / 等级** | 初执笔 → 键上飞仙，带经验条 |
| **三属性** | 迅捷 / 精准 / 博学，S / A / B+ / B / C 判档 |
| **效率诊断** | 用规则把数据翻译成一句可执行建议（换码表 / 调候选顺序 / 改键位 / 换方案），每条带最小样本量 |

## 1.3 可视化

- **键盘热力图**：按布局签名分套保存（最多 8 套），自动选「最近用过且字母键 ≥8」的那套（彻底修掉「永远卡在 QWER」）；每格上行键名、下行百分比；可点一下手动刷新；注明按每次按键计数、不同键盘同名键合并。
- **时段分布**：24 根柱，柱子越高颜色越实，峰值标「最活跃 20:00–21:00 · 占 23% 的字」；**可切「按小时 / 按星期」**（7 根，周一→周日）。
- **词云**：字号 = 词频、高频偏暖色；**默认关闭**，开启才记、关闭顺手清空；只统计 2~6 个纯汉字词，每周期上限 300 词；布局只在打开页面时算一次并缓存，无动画、无后台计算、绝不联网。
- **方案对比卡**：按生涯累计列每个方案的字数 / 均速 / 首选率，条形按字数占比。
- **「这些是什么意思？」解释区**：段位、等级、迅捷/精准/博学、各项指标各一句话讲清。

## 1.4 分享

- **分享文本**：六块结构（段位 → 综合 → 节奏 → 字词/编码分布 `███░░░░░` → 最高频键 → 出处），一行一项用 ` · ` 串联，不依赖列对齐，任何字体机型都不错位；可自选包含热力图 / 方案对比 / 效率诊断 / 语音 / 时段 / 词云。
- **分享长图**：深色渐变底 + 圆角卡片，段位卡带渐变徽章环 + 境界首字 + 经验条 + 三属性 chip；速度卡分极速/均速两列；热力图带「最高频键」小注；图标全部 Canvas 绘制，不打包图片资源。
- **4 套分享图配色**：深海夜色 / 宣纸 / 霓虹 / 暖沙。只换配色不换版式，记住上次选择。
- **评级与称号跟随所选周期**：看生涯是长期画像，看今日是今天状态。

## 1.5 入口

- 首页「输入统计」卡片。
- 键盘左上角「⋮」菜单新增「输入统计」。
- 可在键盘 yaml 里绑命令 `open_input_stats` 给任意按键。

# 二、V2 全新增加：语音统计（V1 只有「声情意象」动效，没有任何统计）

V1 的语音功能是**看得见**的（11 种动效），但**没有数字**。V2 加了一套与打字统计完全隔离的语音账本。

## 2.1 指标（四行结构）

1. **本周期**：N 次 · 共 H:MM · N 字
2. **累计**：N 次 · 共 H:MM · N 字
3. **平均每次**：N 秒 · N 字，+ **语音后改动比例**
4. **最近一次**：N 秒 · N 字 · 时间点（今天显示 `23:12`，非今天显示 `10-29 21:04`）

## 2.2 关键设计

- **字数由 ASR 最终文本直接给出**，会话结束后延迟 0.9 秒落账——两种回调时序都能统计到（此前「33 次才 87 字」就是因为这个）。
- **没上屏文字的会话不计次数**（取消、识别失败不污染数据）。
- **改字率自己算**：「语音结束后 20 秒内按退格次数 ÷ 本次语音字数」，不依赖外部应用上报（原先依赖 asrkb，环境不返回就永远显示「—」）。
- **「语音后改动比例」开关（默认开）**：关掉后统计页、分享图、分享文本**三处同时隐藏**。
- **「清空语音统计」**：只清语音账、打字统计一字不动，会话态一起归零。
- **周期口径与打字统计完全统一**（同一处 `stampOf()`），不再出现「本周语音数比打字数差一天」。
- **三处同源**：统计页 / 分享文本 / 分享图用同一套文案与周期。
- 本周期无语音时显示「今日还没有语音输入」，不再显示「0 次 · 共 0:00 · 0 字」。

# 四、V2 增加的次级功能（6 项）

## 4.1 明文导出 + 离线网页解密器

- **明文导出**：备份可以导出成**不加密的 txt**，方便自己看、迁移、灌进别的工具。
  三步流程（选内容 → 选格式 → 风险确认），不再出现「安全提示太长把列表挤出屏幕、只能点取消」。
- **离线网页解密器**：附带一个**单文件 HTML**，浏览器打开即可解密 `.dahibak`——不联网、不装软件、不上传。
  **给「哪天 App 装不上了，我还能打开备份」留一条后路。**

## 4.2 Rime 调频词表导出（跨端到电脑）

- 把本机「候选排序」记录导出成**标准 Rime 调频词表**（`词<TAB>编码<TAB>权重`）。
- 编码按「词」去主词库 `*.dict.yaml` 反查，因此**电脑端小狼毫能直接导入**。
- 这就是你一直想要的：**手机上调好的候选顺序，带到电脑上用，不用两端各改一遍**。

## 4.3 备份提醒的可靠性修复

- **弹窗（6h 节流）与通知（12h 节流）两条通道各自计时**——此前共用同一时间戳，通知一发就挡住 6 小时的弹窗。
- **通知被系统禁用时不再「静默消耗」提醒机会**：先判断能否发通知，发不出去不记账。
- **写文件失败不重置备份倒计时**：只有真正成功才记账。
- 「标记已备份」加入确认框，避免误点白等一个周期。

## 4.4 自定义短语：可编辑 + 匹配根治 + 文件导入

- **可编辑**（原来只能删了重建）。
- **匹配根治**：raw input 与 preedit **双串比对**，规范化去掉空白 / 不间断空格 / 全角空格 / 撇号 / 间隔号 / 零宽字符——大小写、全半角、软键盘空格都不会漏匹配。
- **短语候选项默认排最前**。
- **自检行**：管理页显示「上次组字 / 预编辑 / 是否命中」，排查「为什么没触发」一秒钟搞定。
- **支持从文件导入**短语表。
- 短语上屏单独埋点，计入输入统计。

## 4.5 首页 6 分组重构

- 首页从固定结构改为 **6 个分组**（V1 的「设置项排序」只能排 5 个组且不能改名）。
- **每个分组可改名**；全部设置项可拖动排序，支持上移 / 下移 / 置顶 / 垫底 / 恢复默认。
- 升级后自动清一次旧的顺序，不会错位。

## 4.6 全新品牌视觉

- **应用图标**：「ㄓ」双横起浪（中横、底横都是波浪，一条连续 path、拐角自然无重叠）+ 太极（右凹陷位置）。
  背景 **墨水蓝渐变**（`#16456B` → `#0E2C3E`，左上亮、右下深，有纵深），与亮金笔画对比度 **9.29 : 1**。
  五个密度 PNG 全部重绘（48/72/96/144/192，含圆形版）+ 矢量自适应图标。
- **标题内联标记**：工具栏标题里嵌入同一个矢量标记（`ImageSpan`），窄屏不再被截断成「同文输入法大海版…」。
- **启动页**同步换标。

既然都选择用了离线同文，就别再裸奔了。
放在外部存储，离线等于无，任何有存储权限的app都会无限扫描和任意读取你的外部存储数据。流氓应用最无底线喜欢的，就是你外部存储的这些数据。
既然用了离线，就不要再将你输入过的所有明文暴露。名字，账号，地址，密码，身份号，银行卡号，手机号···不要说你输入过的所有，都不重要！
为了外部目录那一点方便，牺牲安全何必呢？只要出事一次就吃刁大的亏。

## 二、备份与还原（加密）

- 文件格式：`magic(8B) | version(1B) | salt(16B) | iv(12B) | AES-256-GCM(密文+tag)`，**绝不明文落盘**。
- KDF：PBKDF2-HMAC-SHA256，20 万次迭代，256 bit。
- **7 个可独立勾选项**：首选项 / 剪贴板 / 收藏夹 / 声情意象 / 候选排序 / 自定义短语 / 键盘背景（图片、GIF、视频 ≤4MB）。

- 还原前显示「备份时间 / 来源版本 / 文件大小」；备份来自更新版本时明确提示（不是密码错）。
- 密码错与文件损坏分别提示，不再一律说“密码错误”。

- **声情意象 11 种动效**：清纹徐流、静息沉光、星星点点、环漪悠漾、碧浪腾舒、明律铿锵、迷雾萦回、海浪怒吼、一片空白、随遇随机、声随情迁。
  可拖动排序、可独立取色、有最大振幅上限与自适应灵敏度；两个快捷入口（工具栏 ♬ / 键盘左上角三点菜单）。

## 一、先说全篇最特别的一件事：声情意象

**这是本项目原创、目前没有第二款输入法做过的功能。**

用语音输入时，键盘底部会随着你的声音起伏流动。不是那种机械的"音量条"——是八套**带情绪内核**的动效，每一套对应一种说话状态：

| 动效 | 情绪内核 | 强度 |
|---|---|---|
| 清纹徐流 | 平和舒缓、娓娓道来 | ★★☆☆☆ |
| 静息沉光 | 沉静内敛、若有所思 | ★★☆☆☆ |
| 星星点点 | 轻快跳跃、心情明亮 | ★★★☆☆ |
| 环漪悠漾 | 温润从容、不急不缓 | ★★★☆☆ |
| 碧浪腾舒 | 兴致盎然、灵动外放 | ★★★★☆ |
| 明律铿锵 | 理性清醒、条理清晰 | ★★★★☆ |
| 迷雾萦回 | 思绪纷乱、遐想恍惚 | ★★★★☆ |
| 海浪怒吼 | 澎湃汹涌、大海无量 | ★★★★★ |

还有三种"模式"：

- **一片空白**：关闭动效，只留干净键盘。
- **随遇随机**：每次语音输入随机挑一套，天天不重样。
- **声随情迁**：**根据你声音的活跃度，在八套动效之间自动过渡**——轻声细语时是清纹徐流，越说越激动会自然推到海浪怒吼。灵敏度可调。

能调的细节：动效颜色（跟随键盘配色，或固定一个颜色）、动效透明度（100%–150%，主题偏淡时可以加深）、最大振幅上限（避免盖住候选）、顺序（拖动排序）、工具栏 ♬ 按钮一键切换。

> 为什么值得单独说：键盘是"看不见的器官"，绝大多数输入法只在**结果**（打出什么字）上优化，没有人在**过程**（说话/打字时的身体感）上做过设计。声情意象是把"说话的情绪"变成可见的形状——这也是这个版本最想让你先看到的东西。

## 二、第二件：键盘的每一条参数，现在都在你手里

同文最迷人的地方是「什么都能改」；最折磨人的地方是「只能用 YAML 改」。

想要按键圆角大一点、候选栏矮一点、气泡阴影淡一点、工具栏图标换个颜色——
都得打开主题目录里那份几百行的 yaml，在一堆 `key_back_color` / `keyboard_padding` 里
凭经验填数字，然后「部署」、回键盘看、不对再改。想装别人做的皮肤更麻烦：先学会把文件放对地方、改对 `style`。

**大海版把这一整条链路删掉了。**

| 以前 | 现在 |
|---|---|
| 打开编辑器找键名 | 点开「样式编辑」：18 组颜色 / 30 项尺寸，按分组排好 |
| 手填 `#RRGGBB` | 取色盘：色相条 + 饱和度&明度面板 + A/R/G/B + 十六进制 + 透明度 |
| 凭经验猜 dp 数值 | 拖滑杆，预览立刻变——用的是**你真实的键盘背景图**，不是示意色块 |
| 改完部署、重启、回键盘看 | 改完即时生效，键盘视图当场重建 |
| 皮肤只是"一个包"，别人装了还怕撞主题 | **一键导出皮肤 JSON，别人一键导入**，配色尺寸圆角间距原样带走 |
| 想反悔 | 「恢复默认」，或换回上一个模板槽 |

细节不省：三层覆盖（颜色 fallback 链 → 30+ 中文别名键 → 按键层 `GradientDrawable`）
保证**任何第三方主题都能改**——包括那些拿图片当按键底色的主题（这类主题以前怎么改颜色都没反应，
因为它的底色根本不是"颜色"）。

**怎么把皮肤给别人：**

1. 调好 → 样式编辑 → 模板 → 保存到自定义槽 → 导出 JSON
2. 把 JSON 发出去
3. 对方：样式编辑 → 模板 → 导入 → 选中 → 应用

不需要他懂任何配置，也不需要他重启。

> **这才是同文「自由」该有的样子**：自由不该以"必须会写配置"为门槛。
> 你做一套，朋友导入就能用；他在你的基础上改两笔，再导出给下一个人。
> 同文生态里目前没有第二款做到这一点——这不是"又多了一个主题可选"，
> 而是**皮肤第一次变成了可以互相传递的东西**。

### 🔐 备份与还原 —— **军工级加密，绝不明文落盘：你的数据只有你能读取、你做主；别人拿去只能是一堆乱码废物**

```
文件格式：magic(8B "DAHIBAK1") | version(1B) | salt(16B) | iv(12B) | AES-256-GCM(ciphertext + 16B tag)
密钥派生：PBKDF2-HMAC-SHA256 (200,000 次迭代) → 256-bit Key
```

- 可选备份：**首选项 / 剪切板 / 收藏夹 / 声情意象参数**
- 还原时同样可单项勾选，**整体覆盖**所选数据，有确认提示
- 文件被其他任何应用、任何人读取也只能得到一堆乱码

## 📥 下载与安装

1. 进入 **[Releases](https://github.com/githubms68/trime-dahi/releases/latest)**
2. 下载最新 **`...-arm64-v8a-release.apk`**（现代手机首选，旧机型选 `armeabi-v7a`）
3. 传手机安装（首次需允许「安装未知来源应用」）
4. 系统「语言和输入法」中启用 **「同文输入法大海版」** 并切换
5. 首次自动部署 Rime 方案，稍等即可使用

支持 ABI：`arm64-v8a`（推荐） / `armeabi-v7a` / `x86` / `x86_64`

## ❓ 常见问题

| 问题 | 答案 |
|------|------|
| **能和官方同文一起装吗？** | 能，包名不同，互不影响 |
| **语音没反应/提示未找到服务？** | 1) 安装「说点啥」 2) 开启「允许外部输入法联动 (AIDL)」 3) 后台锁定「说点啥」常驻 |
| **声情意象动效不显示/卡顿？** | 降低「最大振幅上限」、关闭「工具栏按钮」省资源；动效为纯自绘，无 GPU 依赖 |
| **提示签名异常/来源未知？** | 个人自签名、非应用商店分发，属正常现象 |
| **怎么更新？** |  大海版老用户Releases下载新版直接覆盖安装更新，重新覆盖安装不会清除旧版数据。**但仍然建议更新前，用大海版自带加密备份进行备份** |
